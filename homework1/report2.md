## 解題說明

本題要求實現一個用遞迴函式來計算集合 S 的 powerset（所有子集合）。

### 解題策略

1. 每個元素有兩種選擇：選入子集合或不選入子集合。
2. 用遞迴往下處理下一個元素。
3. 當所有元素都處理完後，輸出子集合，形成 powerset 的一個子集合。
4. 程式可處理任何數量的元素。

## 程式實作

```cpp
#include <iostream>
using namespace std;

void ps(int S[], int n, int sub[], int sz, int id) {
    if (id == n) {
        cout << "{";
        for (int i = 0; i < sz; ++i) {
            cout << sub[i];
            if (i != sz - 1) cout << ",";
        }
        cout << "}" << endl;
        return;
    }
    ps(S, n, sub, sz, id + 1); // 不選當前元素
    sub[sz] = S[id];
    ps(S, n, sub, sz + 1, id + 1); // 選當前元素
}

int main() {
    int S[] = {1, 2, 3};
    int n = 3;
    int sub[3];
    ps(S, n, sub, 0, 0);
    return 0;
}
```

## 效能分析

時間複雜度：O(2^n)，每個元素有選或不選兩種可能，共有 2^n 個子集合。
空間複雜度：O(n)，遞迴堆疊最大深度為 n，subset 陣列大小為 n。

### 結論

程式能列出集合的所有子集合，結果也符合 powerset 的定義。  
用遞迴方式處理每個元素的選與不選情況，程式邏輯簡單易懂，在不同大小的集合都可以運作。  
測試時包含了空集合、單一元素、多個元素，及較大的集合，結果都能產生子集合，驗證了程式的正確性。  

### 申論及開發報告
  
遞迴可以讓整體流程輕觸且更好理解，每一層都在處理一個元素要不要加入子集合。  
逐步累積就能把所有可能的組合都產生出來。  
遞迴本身的呼叫方式也符合 powerset 的結構，過程中也能看到堆疊的運作方式。
